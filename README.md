# fb-clone-website

This project is a **Facebook website clone** created as part of our **Git and GitHub tutorial**. The main purpose of this project was to practice using Git for version control while building a simple web interface inspired by Facebook.

## 📌 About the Project

The **fb-clone-website** recreates some of the basic visual elements and layout of a social media platform. It was developed as a learning project to understand how a website can be structured and managed using Git.

While working on this project, I practiced creating files, making changes, tracking those changes with Git, creating commits, and managing the project using GitHub.

## 🎯 Purpose

The main goals of this project were:

* To learn the basics of **Git and GitHub**
* To understand how version control works
* To practice creating and managing a web project
* To learn how to track changes using Git commits
* To become familiar with uploading and managing projects on GitHub
* To improve my understanding of website structure and design

## 🛠️ Technologies Used

This project was created using basic web development technologies:

* **HTML** – Used to create the structure of the website
* **CSS** – Used for styling and designing the interface
* **JavaScript** – Used for adding basic interactivity, if required
* **Git** – Used for version control
* **GitHub** – Used to store and manage the project repository

## 📚 What I Learned

Working on this project gave me practical experience with Git commands and the Git workflow. I learned how to initialize a repository, check the status of files, stage changes, create commits, and push the project to GitHub.

Some of the Git concepts I practiced include:

```bash
git init
git status
git add .
git commit -m "Initial commit"
git branch
git checkout
git push
```

This project helped me understand how Git can be used to safely manage changes during the development of a website.
